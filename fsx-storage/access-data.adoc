= Zugriff auf Ihre FSx for ONTAP Dateisystemdaten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können von Ihrem lokalen Netzwerk aus auf Ihre FSx for ONTAP Dateisysteme zugreifen, indem Sie Volumes für NAS-Clients und iSCSI-LUNs für SAN-Clients einbinden.

link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/supported-fsx-clients.html["Zugriff auf Daten"^]Die Dokumentation zu Amazon FSx for NetApp ONTAP enthält Informationen darüber, wie auf Daten zugegriffen werden kann.

Der Mountpunkt für Volumes kann auch in NetApp Workload Factory abgerufen werden.



[[get-mount-point-for-volumes-in-netapp-workload-factory]]
== Abrufen des Mountpunkts für Volumes in NetApp Workload Factory

Der Mountpunkt eines Volumes kann verwendet werden, um das Volume als CIFS-Freigabe oder auf einem NFS-Client einzuhängen.

.Schritte
. Melden Sie sich bei der link:https://console.netapp.com["NetApp Console"^] an.
. Die Auswahl erfolgt im Menü image:workloads-menu-icon.png["Das Hamburger-Menüsymbol wird für die Navigation zu Workloads, dem Menüpunkt für Workload Factory, verwendet"], *Workloads* > *Volumes explorer* > *FSx for ONTAP*.
. Wählen Sie das Aktionsmenü für das Volume, dann *Grundlegende Aktionen* und anschließend *Einbindungsbefehl anzeigen*.
. Im Dialogfeld „Mount-Befehl“ kann *Copy* ausgewählt werden, um den Befehl für den NFS-Mountpunkt oder die CIFS-Freigabe zu kopieren. Anschließend erfolgt die Eingabe des kopierten Befehls im Terminal.
. *Schließen* auswählen.
