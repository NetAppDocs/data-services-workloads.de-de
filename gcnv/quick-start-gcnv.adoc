= Schnellstart für Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Zum Einstieg in Google Cloud NetApp Volumes ist zunächst Google Cloud einzurichten und anschließend ein System zu erstellen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] link:set-up.html["Einrichtung von Google Cloud NetApp Volumes"]
[role="quick-margin-para"]
Bei Google können Sie ein Dienstkonto erstellen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"] link:add-roles.html["Rollen zuweisen"]
[role="quick-margin-para"]
Um mit Google Cloud NetApp Volumes arbeiten zu können, benötigen Sie die entsprechenden Berechtigungen, und Ihnen muss die Rolle „Google Cloud NetApp Volumes admin“ oder „Google Cloud NetApp viewer“ zugewiesen sein.

[role="quick-margin-para"]
image:role_gcnv.png["Ein Screenshot der Rolle Google Cloud NetApp Volumes."]

[role="quick-margin-para"]
Die Zuweisung der richtigen Rollen an Mitglieder erfolgt über die NetApp Console.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"] link:create-discover-systems.html["Fügen Sie ein System hinzu"]
[role="quick-margin-para"]
In der NetApp Console wählen Sie nacheinander *Add System*, dann *Google Cloud Platform*, anschließend *Google Cloud NetApp Volumes* und schließlich *Discover* aus. Anzugeben sind die Details zum Servicekonto und zum Google Cloud-Projekt.
