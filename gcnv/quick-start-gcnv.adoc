= Schnellstart für Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Der Einstieg in Google Cloud NetApp Volumes erfolgt durch das Zuweisen Ihrer NetApp Console Rolle, das Hinzufügen von Anmeldeinformationen und die Erkennung eines Systems.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] link:../gcnv/add-roles.html["Rollen zuweisen"]
[role="quick-margin-para"]
Die Zuweisung der richtigen Rollen an Mitglieder erfolgt über die NetApp Console.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Anmeldeinformationen hinzufügen"]
[role="quick-margin-para"]
In der NetApp Console lassen sich Anmeldeinformationen für Google Cloud NetApp Volumes hinzufügen.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"] link:../gcnv/create-discover-systems.html["Fügen Sie ein System hinzu"]
[role="quick-margin-para"]
In der NetApp Console erfolgt die Ermittlung eines Systems anhand der Anmeldeinformationen, des Google Cloud-Projekts und der unterstützten Region.
