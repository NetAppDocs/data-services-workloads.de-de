= Schnellstart für die Migration zu Google Cloud VMware Engine mit dem VMware workloads migration advisor
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Beginnen Sie mit dem VMware Migration Advisor, um Ihre aktuelle Infrastruktur zu Google Cloud VMware Engine zu migrieren und dabei Google Cloud NetApp Volumes als externe NFS-Datenspeicher zu verwenden.

Bevor Sie beginnen, sollten Sie mit dem link:../fsx-storage/permissions-reference-fsx.html["Berechtigungen für FSx for ONTAP für NetApp Workload Factory"^] vertraut sein.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Eins"] Anmeldung bei Workload Factory
[role="quick-margin-para"]
Sie müssen link:../setup/sign-up-and-log-in.html["ein Konto bei Workload Factory einrichten"^] und sich bei der NetApp Console anmelden.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Zwei"] Hinzufügen von Anmeldeinformationen und Berechtigungen
[role="quick-margin-para"]
Die Auswahl des Produkts link:../fsx-storage/permissions-reference-fsx.html["Berechtigungsrichtlinien"], das Ihren Anforderungen entspricht.

[role="quick-margin-para"]
Wenn Sie keine Berechtigungen erteilen, können Sie Workload Factory für VMware verwenden, um teilweise fertiggestellte Codebeispiele zu kopieren.

[role="quick-margin-para"]
Wenn Sie sich dafür entscheiden, Berechtigungen zu erteilen, müssen Sie link:../fsx-storage/add-credentials.html["Anmeldeinformationen manuell zu einem Konto hinzufügen"]; dazu gehört auch, ein GCP-Dienstkonto mit den erforderlichen Berechtigungen zum Anzeigen und Managen von Google Cloud NetApp Volumes Ressourcen, der VPC Konfiguration und der Google Cloud VMware Engine Datenspeicheranbindung bereitzustellen.

[role="quick-margin-para"]
link:../fsx-storage/add-credentials.html["Informationen zum Hinzufügen von Anmeldeinformationen und Berechtigungen"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Drei"] Hochladen von VM Inventardaten
[role="quick-margin-para"]
Im Planungszentrum können Sie Inventardetails zu Ihrer aktuellen VM-Umgebung hochladen. Zum Erfassen Ihrer aktuellen VM-Konfiguration und zum Hochladen der Daten in das Planungszentrum stehen das Datenerfassungsskript, RVTools oder NetApp Data Infrastructure Insights zur Verfügung.

[role="quick-margin-para"]
link:upload-vm-inventory.html["So laden Sie VM-Inventardaten hoch"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Vier"] Erstellung eines Deployment-Plans mit dem VMware migration advisor
[role="quick-margin-para"]
Starten Sie den VMware Migration Advisor und konfigurieren Sie die VM-Umgebung, die Sie auf der Google Cloud VMware Engine-Infrastruktur unter Verwendung von Google Cloud NetApp Volumes als externe NFS-Datenspeicher erstellen möchten.

[role="quick-margin-para"]
link:launch-migration-advisor-gcve.html["Es wird erläutert, wie der VMware migration advisor zum Erstellen eines Deployment-Plans verwendet wird."].
