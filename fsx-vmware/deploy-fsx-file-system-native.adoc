= Einsatz des empfohlenen FSx for ONTAP Dateisystems
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Nachdem Sie überprüft haben, dass das empfohlene FSx for ONTAP Dateisystem (oder in einigen Fällen mehrere Dateisysteme) Ihren genauen Anforderungen entspricht, können Sie Workload Factory verwenden, um das System in Ihrer AWS-Umgebung einzusetzen.

Die Anweisungen in link:../fsx-storage/create-discover-systems.html["Erstellung eines FSx for ONTAP Dateisystems in NetApp Workload Factory"^] unterstützen Sie dabei, das FSx for ONTAP Dateisystem gemäß der von Workload Factory empfohlenen Konfiguration einzusetzen. Sie können die Schritte unter *Advanced create* in den Anweisungen verwenden, um das Dateisystem vollständig anzupassen.
